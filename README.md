# Beat Studio

Browser-native beat generator rebuilt from the original Beat Generator prototype.

## Features
- Afrobeats, Amapiano, Trap and Drill generation
- Seeded beat engine with BPM and key metadata
- Web Audio playback with drums, bass, chords, leads and vocal-like synth textures
- Mobile-friendly studio interface
- Offline WAV rendering and browser download
- No API keys or server runtime required

## Deployment
This is a static web app. The root entry point is `index.html`, so Vercel can serve it without a framework adapter or server runtime.
