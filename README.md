# Beat Studio

Browser-native beat generator rebuilt from the original Beat Generator prototype.

## Features
- Afrobeats, Amapiano, Trap and Drill generation
- Deterministic seeded beat engine with BPM/key metadata
- Web Audio API playback with drums, bass, chords, leads and vocal-like synth textures
- Mobile-friendly studio UI
- Offline WAV rendering and browser download
- No API keys or server runtime required

## Development
This is a static site. Open `index.html` directly or serve the folder with any static HTTP server.

## Deployment
Vercel can deploy the repository as a static site. The root entry point is `index.html`, so no framework adapter or build server is required.
